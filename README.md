# 🧠 AI-Mental-Health

AI 心理健康管理平台，提供智能心理疏导与情绪追踪服务。

各页面预览详见demo文件夹
## 📖 项目简介

> 结合 AI 大模型的自然语言对话能力，为用户提供 7×24 小时心理健康支持，同时支持情绪日记记录与数据可视化分析。

---

## ✨ 功能模块

### 🧑‍⚕️ 用户端

| 模块 | 说明 |
|------|------|
| 🤖 AI 心理对话 | 流式响应，实时交互体验 |
| 📝 情绪日记 | 记录每日心情，追踪情绪变化 |
| 📚 知识文章 | 阅读心理健康相关科普内容 |

### 🛠️ 管理端

| 模块 | 说明 |
|------|------|
| 📊 数据看板 | ECharts 可视化图表 |
| 💬 咨询记录 | 查看管理用户对话历史 |
| 📋 情绪日志 | 用户情绪数据管理 |
| ✍️ 文章发布 | 富文本编辑器发布内容 |

---

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 框架 | Vue 3 + Vite |
| UI 组件库 | Element Plus |
| 状态管理 | Pinia |
| 图表 | ECharts |
| 富文本 | WangEditor |
| HTTP 请求 | Axios |

---

## 🚀 快速开始

### 环境要求

- Node.js >= 16
- pnpm >= 8

### 安装依赖

```bash
pnpm install
```
